This is the first entry. The site is online, so the log starts.

## Why a log

A portfolio shows finished things. Most of what I do is not finished: a study
session, a pipeline that failed four times before it passed, a tool I tried and
dropped. That part usually disappears. Here it gets written down.

So this site has two halves:

- **Projects**: what I have built, with links to the code.
- **Log**: notes on what I am studying and building, including what went wrong.

## How it is built

The site is generated by a small Rust program. No framework.

```text
site.toml        profile, experience, projects
content/log/*.md one Markdown file per entry
static/          css and js
src/main.rs      reads all of the above, writes ./dist
```

Writing a new entry means adding one file:

```toml
+++
title = "Entry title"
date = "2026-11-16"
tags = ["rust"]
summary = "One line for the index."
+++
```

Then `git push`. GitHub Actions builds the program, runs it, and publishes the
output to GitHub Pages.
